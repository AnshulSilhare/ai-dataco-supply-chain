Model Governance & Limitations
  • Feature Reduction: The model relies exclusively on 4 core predictive drivers. If other factors (like destination country customs strikes) occur, the model cannot capture them directly.
  • SLA Fluidity: Hardcoded SLA threshold assumptions must be regularly reviewed against carrier contractual updates to maintain accuracy.
  • Feature Drift: Seasonal volume spikes (e.g., Q4 holidays) can cause data distributions to drift, requiring periodic model retraining.
  • Categorical Sparsity: Dropping secondary categorical dimensions like product category reduces model overfitting but limits sub-segment drift detection.

DataCo DSS Guide

SCM Business Challenge

Late delivery SLA violations erode margins by up to 25%. This DSS acts as a Prescriptive Mitigation Engine - leveraging the benchmark DataCo Smart Supply Chain Dataset to quantify SLA liability and determine when to spend expedited freight costs to salvage net order profits.

Operations Decision Logic (ROI)

Prescriptive Action: Intervene if Expected Profit (No Intervention) < Expected Profit (Expedited Shipping).

How to Interpret the SHAP Waterfall

• Base Value: Average historical probability of late delivery.
• Red blocks (+): Increase delay risk for this specific order.
• Green blocks (-): Decrease delay risk, pulling the probability down.

How to Use the Batch Engine

  1. Upload Data: Drop your CSV/Excel file with order records. Use the sample template as a starting point.
  2. Set SLA Penalty Rate: The % of order sales value forfeited when delivery breaches the SLA window.
  3. Set Intervention Cost: The flat fee (per order) to expedite a risky shipment and avoid the penalty.
  4. Run & Export: Get risk flags, financial ROI, geographic map, and download a formatted Excel report.
